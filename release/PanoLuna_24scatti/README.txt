PanoLuna - работа из 24 снимков
Камера: Insta360 Luna Ultra, объектив 1x
Сетка: 4 строк x 6 столбцов
Перекрытие: 30%
Tilt: -52.0 .. 52.0 градусов

1) PTGui: откройте проект PanoLuna_24scatti.pts
   и перетащите 24 фотографии: углы pan/pitch уже заданы по индексу.
   Выход: equirectangular 27654x13827 (2:1).

2) Pano2VR: два пути.
   a) проект PanoLuna_24scatti.p2vr, который указывает на equirectangular
      сшитую в PTGui (переименуйте в PanoLuna_24scatti_equirectangular.jpg).
   b) Pro > File > Import Papywizard, с PanoLuna_24scatti.papywizard.xml.

3) PanoLuna_24scatti.csv - таблица углов по строкам.
