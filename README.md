# panoluna
PanoLuna — Android-приложение-компаньон для камеры Insta360 Luna Ultra. Оно автоматизирует съёмку набора отдельных кадров сферической панорамы: камера остаётся ответственна за сами фотографии, а приложение последовательно перемещает гимбал между точками и запускает затвор. Полученные изображения предназначены для последующей сшивки на компьютере.
